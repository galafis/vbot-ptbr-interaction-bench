# Contributing · Contribuir

Use Node 22+, run `npm test`, and include an independently calculated example when changing a method. Keep examples synthetic. Document units and distinguish operator assumptions from manufacturer specifications. Do not add device interfaces without documented permission. Open an issue for a reproducible bug or proposed study improvement.

PT: Use exemplos fictícios, rode os testes e registre unidades, hipóteses e limitações. Interfaces de dispositivo exigem documentação e permissão do fabricante.
