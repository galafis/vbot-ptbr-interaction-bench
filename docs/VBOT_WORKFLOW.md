# Working with any Vbot edition · Trabalho com qualquer edição

## English

A standard, demonstration, used or refurbished unit is welcome. An open SDK, source code, root access or low-level control is **not a prerequisite**. This independent project will adapt to whatever the specific robot, app, firmware and manufacturer permit.

1. **Native-only study:** the operator uses documented app controls and built-in features. Observations are typed manually into the offline workbench. Timing, checklists, printed instructions and optional permitted accessories support the exercise.
2. **Permitted export:** if Vbot offers an authorized export, convert it to the repository input contract after checking units, timestamps and privacy. No undocumented endpoint is assumed.
3. **Optional authorized integration:** only after Vbot explicitly documents and permits the relevant interface. Version and permission evidence must accompany an adapter. No such adapter exists in this release.

Initial work uses empty indoor courses and consenting adult operators. Participants choose whether to engage and may stop. Native following is not validated guidance for blind or low-vision users. Emergency-response applications are limited to classroom/synthetic exercises; no fire, rubble or live rescue. A future study involving people or institutions requires appropriate local review and authorization.

The software cannot stop a robot, disable a microphone, enforce a payload limit or guarantee data deletion on vendor systems. Confirm device behavior using the manufacturer's actual mechanisms. A workflow state or simulated result is not physical evidence.

This is an independent proposal by Gabriel Demetrios Lafis, not an announced partnership with Vbot, USP, Natura or SysMap. University involvement would follow the institution's authorization process. No sponsorship has been secured at publication.

## Português

Uma unidade comum, de demonstração, usada ou recondicionada já será bem-vinda. SDK aberto, código-fonte, root ou controle de baixo nível **não são pré-requisitos**. O projeto se adapta ao que o robô, aplicativo, firmware e fabricante permitirem.

1. **Somente recursos nativos:** o operador usa as funções e controles documentados. As observações são preenchidas manualmente na bancada offline. Cronometragem, listas de verificação, instruções impressas e acessórios permitidos podem apoiar o exercício.
2. **Exportação permitida:** se houver exportação autorizada, os dados podem ser convertidos para o contrato de entrada após revisão de unidades, tempos e privacidade.
3. **Integração opcional autorizada:** apenas com interface documentada e permitida pelo fabricante. Não existe adaptador de hardware nesta versão.

A fase inicial usa percursos internos vazios e operadores adultos que aceitem participar. Acompanhamento nativo não equivale a orientação validada para pessoas cegas. Estudos de emergência ficam em sala de aula/cenários fictícios. Estudos futuros com participantes ou instituições dependem das autorizações adequadas.

O programa não para o robô, desativa microfone ou impõe limites físicos. É necessário conferir o estado real nos controles do fabricante. O estado do software não é evidência de comportamento físico.

Proposta independente de Gabriel Demetrios Lafis, sem parceria anunciada com Vbot, USP, Natura ou SysMap. Participação universitária depende de autorização institucional. Não há patrocínio obtido na publicação.
